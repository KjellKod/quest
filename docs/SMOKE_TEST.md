# Quest Smoke Test - Phase Reference

## Overview
This document lists all nine Quest phases with one-line descriptions for smoke testing the Quest orchestration workflow.

## Quest Phases

1. **Intake** - Classify the user request, create the quest brief, and route the workflow.
2. **Plan** - Produce an implementation plan with scope, acceptance criteria, risks, and validation.
3. **Dual Plan Review** - Run two independent plan reviews to detect gaps before implementation.
4. **Arbiter** - Reconcile plan-review feedback into a final approved implementation direction.
5. **Present Plan** - Walk through the approved plan and obtain explicit build approval.
6. **Build** - Implement the approved plan and generate required implementation artifacts.
7. **Dual Code Review** - Run two independent code reviews to identify defects and regressions.
8. **Fix Loop** - Address review findings, revalidate changes, and iterate until resolved.
9. **Complete** - Finalize the quest outputs, record the handoff, and close the workflow.
